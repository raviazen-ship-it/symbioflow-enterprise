# SYMBIOFLOW ENTERPRISE v4.0

Aplikasi B2B Circular Economy Marketplace, 3D WebGL Digital Twin Material Inspector, Trade Finance Net-60, dan Automated Scope-3 Carbon Ledger.

## Cara Menjalankan Secara Lokal

```bash
cd C:\Users\USER\.gemini\antigravity\scratch\symbioflow-enterprise
npm install
npm run dev
```

## Modul Interaktif (7 Tab Utama)
1. **1. Workflow:** Simulator 7 tahap end-to-end dengan ekstraksi dokumen PDF COA/MSDS Sucofindo (`0% - 100%`) dan integrasi langsung ke inspektor 3D.
2. **2. 3D & Bursa:** Katalog residu industri terverifikasi AI Vector Match (`98.4%`, `95.1%`, `92.7%`), 3 mode 3D Three.js (`Granular & Kimia`, `Kontainer 20ft FIBC`, `Peta Simbiosis 3D`), shader `Wireframe`, `Thermal X-Ray`, `Exploded View (1.85x)`, serta simulator kontrak `SPOT ESCROW`, `NET 30`, `NET 60`.
3. **3. Tender & Kredit:** Papan lelang pengadaan terbalik (*Reverse Auction RFQ*) dengan tombol **Ajukan Bid Lebih Rendah (-1.5%)**, plafon kredit Net-60, dan formulir publikasi tender baru.
4. **4. Deal Room:** 4 jalur kontak resmi (WebRTC Video Inspeksi Gudang, Sampel Fisik 15 kg QR-Sealed, WhatsApp Enterprise API Bridge, Dedicated Account Manager) dan ruang chat B2B terenkripsi dengan balasan otomatis serta inspektor lampiran PDF COA.
5. **5. QC & ESG:** Kalkulator penalti moisture basis kering (*dry-basis*), rekonsiliasi 3 arah (*3-Way Matching*: PO, Tiket Timbang IoT `Truck B 9481 UEX`, e-Faktur PPN 11%), dan generator sertifikat karbon Scope-3 terverifikasi ISO 14064-1 & GRI 306.
6. **6. Bisnis & ERP:** Simulator pendapatan bulanan & ARR Chief Business Officer (`Rp 10 Miliar - Rp 250 Miliar / bulan`), 3 paket langganan SaaS, sakelar webhook SAP S/4HANA MM / NetSuite / Odoo / DJP, dan tabel log audit rantai hash SHA-256 ISO 27001.
7. **7. Master .MD:** Penampil spesifikasi lengkap beserta skema SQL produksi PostgreSQL (`PostGIS` + `pgvector`) dengan tombol salin dan unduh `.md`.
